# 令和８年 多治見市三十路式 HP

多治見市三十路式の公式ウェブサイトです。

## 技術スタック

- React 18
- Vite
- Tailwind CSS
- Lucide React (アイコン)

## 開発環境のセットアップ

### 依存関係のインストール
```bash
npm install
```

### 開発サーバーの起動
```bash
# 開発サーバーの起動
npm run dev

# プロダクションビルド
npm run build

# ビルド結果のプレビュー
npm run preview
```

## Vercelでのデプロイ

このプロジェクトはVercelでホスティングされています。

1. GitHubリポジトリにコードをプッシュ
2. Vercelダッシュボードで「Add New Project」を選択
3. GitHubリポジトリをインポート
4. 「Deploy」をクリック

デプロイ完了後、自動的に生成されたURLでサイトが公開されます。
