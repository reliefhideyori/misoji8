# 令和８年 多治見市三十路式 HP

多治見市三十路式の公式ウェブサイトです。

## 技術スタック

- React 18
- Vite
- Tailwind CSS
- Lucide React (アイコン)

## 開発環境のセットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# プロダクションビルド
npm run build

# ビルド結果のプレビュー
npm run preview
```

## デプロイ

このプロジェクトはVercelでホスティングされています。

## ライセンス

Private
